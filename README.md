# Kunal Vaishnav — UI/UX & Product Designer Portfolio

An interactive, responsive portfolio website built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, created directly from Kunal Vaishnav's design presentation.

---

## ✨ Features & Architecture

- **Hero Experience**: Glowing gradient typography matching the Canva presentation, animated role badges, ambient radial lighting, and quick navigation actions.
- **Who I Am**: Detailed designer profile, high-res portrait card, interactive tooling badges (Figma, Adobe XD, Photoshop, Illustrator), and one-click copy email/phone.
- **Categorized Navigation (Contents)**: 
  1. *UI UX* (4 in-depth case studies)
  2. *Social Media* (Marketing creatives & 3D mockups)
  3. *Logo & Branding* (Brand identities: MAS, Villa Messian, Juristir, hlo, VELA)
- **Deep-Dive Case Studies**:
  1. **RSRTC Connect**: Transit travel app for Rajasthan state buses with real-time tracking, seat booking, Be Vietnam Pro design system, and clickable Figma prototype.
  2. **NPrep Profile Experience Redesign**: EdTech retention & goal tracking dashboard for nursing students with gamification streaks and interactive Figma prototype.
  3. **ExamWaliSite Desktop Page**: Modern competitive exam portal featuring search omnibox, mentor proof metrics, and dark-mode web layout.
  4. **Hostel Hub**: Centralized hostel operations system for wardens and students with attendance, room allocation, and outpass management.
- **Live Figma Integrations**: Direct links to all Figma prototype flows and canvas files.
- **Interactive Inquiries & Contact**: Copy email with celebratory confetti, quick contact form with mail client handoff, and direct phone link.

---

## 🚀 Getting Started

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To build for production:

```bash
npm run build
npm start
```
